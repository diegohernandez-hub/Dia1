## Qué pasa hoy

Tesorería arma a mano el archivo que manda al banco. Abren el listado (`node src/cli.js list`), copian id / cliente / fecha / monto a una planilla, y lo guardan como CSV. Cada cierre de mes se va ~una hora y se cuelan facturas que no deberían ir.

María: *las anuladas creo que no, o a veces sí para cuadrar. El Excel de Windows a veces abre mal los acentos. Si pueden filtrar por mes mejor, el de agosto lo necesitamos ya.*

## Pedido

Un comando en la CLI que deje un CSV listo para tesorería.

Algo como:

```
node src/cli.js export-csv
```

Campos que usan: id, cliente, fecha, monto, estado. El nombre del archivo no quedó fijo; a veces lo llaman `facturas.csv` y a veces `export-tesoreria-agosto.csv`.

Si hay filtro por mes, que sea opcional. Monto: en la planilla actual va como número, no como `$1.250.000`.
